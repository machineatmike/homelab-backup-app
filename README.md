# homelab-backup

A personal backup tool. It is used only by its owner and is not offered to
anyone else.

## Privacy policy

- The app stores encrypted backup files in the owner's own Google Drive.
- It can only see the files it created itself (Google Drive scope
  `drive.file`). It cannot read any other Drive content.
- No data is collected, sold, or shared with anyone. Nothing is sent
  anywhere except the owner's own Google Drive.
- Access can be removed at any time in Google Account > Security >
  Third-party connections.
